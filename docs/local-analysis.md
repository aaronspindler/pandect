# Analysis on the Pandect host

Pandect keeps originals and saved results in the case store.
[Native extraction and metadata checks](analysis-extraction.md) and deterministic
analysis remain available when external AI is disabled.

Model checks use [AI Gateway](analysis.md#external-ai-configuration). Case owners
approve the recipients and payloads in
[Case settings](cases.md#external-ai-and-hosted-search). Older local-model results
retain their recorded execution details.
