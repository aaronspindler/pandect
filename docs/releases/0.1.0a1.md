# Pandect 0.1.0a1

**Draft release notes — not published.** Publish only after the
[release checklist](../releasing.md) passes and the owner authorizes it.

Pandect's first public alpha provides a local-first catalogue and processing
workspace for one trusted operator. It retains originals and separates local
extraction, model hypotheses, and operator decisions with versioned provenance.
Optional models require explicit provisioning; optional Cloudflare processing
requires per-item consent to the exact transfer.

## Install

Build locally from the `v0.1.0a1` source tag using Docker Compose. Follow the
[README](../../README.md) for prerequisites and first-use instructions. There
is no Pandect PyPI installation or prebuilt image published by this project.

## Important boundaries

- Alpha quality; no authentication. Loopback-only, one trusted operator.
- Plaintext evidence and backups; protect the host and use encrypted storage.
- Native media execution is isolated and bounded, not a guarantee against every
  parser/kernel vulnerability or a certification of forensic integrity.
- Upload defaults: 2 GiB/file, 8 GiB/batch, 50 files; decoding/output limits may
  reject smaller compressed inputs. Probing shares one processing slot.
- Model output and gallery scores are uncertain; no commercial-clearance or
  training-data-rights assurance is provided by the source license.

## Existing installations

Stop the legacy Compose project, back up the complete private data directory,
then follow [the upgrade guide](../operations.md#upgrade). Setup introduces
checkout-specific project identity and prepares verified public model-file
permissions. Evidence protection migrations intentionally reject some parent
deletions. Restore the matching full backup and source revision to roll back.
