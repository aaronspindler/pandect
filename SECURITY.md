# Security policy

Pandect is in active development. Reports against the current `main` branch are
in scope. Include the affected commit or release and your deployment type.

Use the [GitHub private reporting form](https://github.com/aaronspindler/pandect/security/advisories/new)
when available. If the form is unavailable, [request a private security
contact](https://github.com/aaronspindler/pandect/issues/new?template=security-contact.yml).
Share details only after the maintainer provides a private channel.

Include the impact, prerequisites, and minimal reproduction steps using synthetic
data. Review diagnostic output before sharing it. Keep real investigation
material, identifying information, credentials, and backups out of reports.
Coordinate public disclosure with the maintainer.

Operators can find configuration and private logging guidance in the
[operations guide](docs/operations.md).
