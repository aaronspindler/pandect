# Security policy

Pandect is in active development. Reports against the current `main` branch are
in scope. Include the affected commit or release and your deployment type.

Use the [GitHub private reporting form](https://github.com/aaronspindler/pandect/security/advisories/new)
when it is available. If the form is unavailable, [request a private security
contact](https://github.com/aaronspindler/pandect/issues/new?template=security-contact.yml)
with a generic issue. Share details only after the maintainer provides a
private channel.

Include the impact, prerequisites, and minimal reproduction steps with
synthetic data. Review diagnostic output before sending it. Keep real
investigation material, identifying information, credentials, and backups out
of reports. Coordinate any public disclosure with the maintainer.

See [deployment and private logging guidance](docs/operations.md) for operator
configuration.
