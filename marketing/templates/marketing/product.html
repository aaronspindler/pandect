Available now

From gathered material to a clearer case.

These capabilities are implemented. Supported local checks run in your installation; model-assisted tools and geographic services have separate setup requirements below.

Private cases and collaboration

Create cases with one owner. Invite viewers or editors by email, manage their access, and keep each investigation’s material together.

Evidence with its originals

Upload files or capture text, messages, calls, and location observations. Retain source details and checksums; archive and restore evidence without replacing originals.

Search within a case

Search captured text, messages, supplied transcripts, and extracted passages. Open the matching source or retained extraction version from the result.

Automatic local checks

Eligible new evidence queues text extraction, printed-English image recognition, metadata checks, identifiers, dates, keywords, and possible plate readings.

People, vehicles, and maps

Maintain case people, contact details, social-account records, and vehicles. Map recorded locations and person-linked points of interest with source lists.

Imports you can review

Import supported Asset Location CSV exports and the documented iMessage HTML format. Confirm timezone and record associations; retain the source file and links to imported records.

Findings beside the evidence

See source-linked highlights alongside each original and in the case Findings workspace. Inspect processing history, rerun checks, and record review decisions.

Reports and comparisons

Inspect possible vehicle trips, call timing, location coverage, and exact file duplicates. Run focused comparisons of wording, communication patterns, and reported locations.

Speech transcription

Transcribe English speech in supported WAV recordings using a configured private runtime, or an explicitly selected and approved external AI route.

Model-assisted analysis

Request topic suggestions, claims and commitments, conversation summaries, and comparisons by meaning. Treat model output as derived suggestions to review.

Geographic lookups

Look up candidate addresses or coordinates and retain nearby map context. Configure private services or approve external lookups; review estimates before using them.

Supported formats

Keeping a file and analyzing it are different.

Evidence storage supports more files than automated analysis. Each method has format and resource limits, with incomplete or unsupported outcomes shown in its results.

Document text and image recognition

Native extraction supports UTF-8 text and unencrypted PDFs with embedded text. Local OCR reads printed English in JPEG/PNG images. Handwriting, Office extraction, and direct recognition of scanned PDF pages are unsupported; retain a separate page image for OCR.

Audio and possible plate readings

Audio metadata and transcription support uncompressed 16-bit PCM WAV in the documented profile; transcription supports English. Plate search is a local JPEG/PNG heuristic and can miss plates or mistake other text for them. It does not identify an owner or driver.

Imports and report coverage

Imports accept documented file profiles, rather than arbitrary exports or live tracking feeds. Reports select at most 500 records; automatic vehicle trips use the latest 500 matching observations. Results disclose truncation, gaps, and unknown values.
