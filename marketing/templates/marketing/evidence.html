Before you begin

Know what each tool needs.

Private services can run on the operator’s server or private network. Additional setup does not necessarily mean sending evidence to a third party.

Included
Runs within the standard installation. Local OCR and plate reading use bundled Tesseract tools and need no external service.
Included; AI optional
Basic analysis runs as included. Optional model suggestions need a configured private model or explicitly approved external AI.
Private setup or approved external AI
Needs a separately configured private model or transcription runtime, or an approved external AI service through Cloudflare AI Gateway.
Configured geographic service
Needs a private or explicitly approved external service for geocoding or map context. These lookups are separate from AI services.

External processing requires explicit approval. A private-service failure never triggers an automatic cloud fallback. This catalogue describes supported capabilities; availability depends on your installation’s setup.
